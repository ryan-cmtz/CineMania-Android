# Evidencia de ejecución en Android

Las capturas se obtuvieron del AVD **Pixel_6_Pro** después de instalar el APK Debug final y abrir la actividad principal. La app inicia y permite navegar entre Inicio y Catálogo.

| Archivo | Evidencia |
|---|---|
| `01_inicio.png` | Pantalla de bienvenida y entrada a la app. |
| `02_catalogo.png` | Catálogo con las pestañas de las cuatro tablas. |
| `03_crud_insert.png` | Alta de una película y mensaje de éxito. |
| `04_crud_editar.png` | Formulario cargado al elegir editar un registro. |
| `04_crud_actualizar.png` | Registro actualizado y mensaje de éxito. |
| `05_crud_eliminar.png` | Registro eliminado y mensaje de éxito. |
| `06_generos.png` | Pestaña de géneros. |
| `07_genero_insert.png` | Alta de un género y mensaje de éxito. |

La evidencia es de un emulador Android (AVD), no de un teléfono físico. El AVD se usó para comprobar instalación, apertura, navegación y operaciones CRUD de películas; también se comprobó el alta de un género.
